    How to Schedule Daily Watch (Windows Task Scheduler)
  

  

    To run automated daily monitoring without opening the browser, schedule run_watch_daily.bat:
  

  
    
    
  1. Press Win + R, type taskschd.msc, and hit Enter to open Windows Task Scheduler.
    2. 
    
  2. In the right pane, click Create Basic Task... and name it SI Scout Daily Watch.
    3. 
    
  3. Select Trigger: Daily, and set the start time (e.g. 08:00 AM).
    4. 
    
  4. Select Action: Start a program.
    5. 
    
  5. In Program/script, browse and select: 
    run_watch_daily.bat (or run_watch_daily.sh on Linux/macOS)
    6. 
    
  6. In Start in (optional), enter the repository folder path.
    7. 
    
  7. Click Finish. The runner will execute daily, checking the watchlist + top 50 earliest-expiring names (capped at 100 queries/day at 1 req/s) and updating watch_log.csv.
