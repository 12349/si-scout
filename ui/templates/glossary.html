Plain-Language Domain Glossary

RDAP (Registration Data Access Protocol)

The modern standard replacement for WHOIS. An authoritative registry query directly to rdap.register.si. An HTTP 404 response confirms the name is not currently registered.

Quarantine / Pending Delete

When a .si domain expires, it enters a mandatory 30-day quarantine. The original owner can renew it during this window. If abandoned, it drops into public availability after day 30.

Twin Signals (.com and .ai)

Checking whether the identical name exists on .com or .ai. If the .com has an active AI product, it proves market interest but poses a severe trademark risk.

NIS2 & Real Identity Requirement

European Union and Slovenian regulations prohibit fake WHOIS data or anonymizing privacy proxies for .si. Using inaccurate contact details will result in registry-wide suspension across all domains.

ARDS (Alternative Dispute Resolution)

Register.si's dispute tribunal. If you register a trademark or well-known public figure, the legitimate owner can file an ARDS dispute and seize the domain without compensation.

16-Day Refund Window Rule

Register.si permits registration fee refunds within 16 days only if the domain has not been activated. Configuring nameservers or DNS records immediately counts as activation and voids the refund.
